Este é um projeto simples feito utilizando HTML, CSS e JavaScript, com o objetivo de praticar eventos em js e manipulação de div em css.

funcionalidades atuais: 
-Criar tarefas
-Excluir tarefas

Funcionalidades futuras: 
-Modo escuro
-Concluir Tarefa

Como utilizar?
baixe o repositório e abra o arquivo index.html no navegador.
Digite sua tarefa no campo de input e clique em add para adiciona-la. Para excluir, clique no "x".
